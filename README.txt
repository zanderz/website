STEVE SANDERS — STATIC WEBSITE
================================

Files:
- index.html
- styles.css
- script.js
- assets/

QUICK START
1. Upload all files to your web host's public/root web directory.
2. Replace hello@example.com in index.html with the real contact email.
3. Replace or add your own project/client examples if desired.
4. The site uses Google Fonts (Inter + Space Grotesk) via CDN. Both are open-source fonts.

DESIGN
Dark technical hero, green accent, clean consulting layout, responsive mobile navigation,
service cards, process/approach section, about section, and contact CTA.

No backend is required. The contact button uses mailto: and therefore does not collect form data.
